# 参考資料

Gemma 4 Developer Agent Competition に関係する論文・資料の読み砕きノートを置く場所です。

原典へのリンクと「我々の設計への活かし方」をセットで記録します。第三者の資料は未検証の前提で読み、方針は自分たちの測定で決めます。

- [強いエージェントにハーネスはどれだけ必要か](harness-paper.ja.md) — arXiv:2609.40303。強いモデルでは凝った足場よりモデル本体が効くが、小さいモデルでは足場が勝つ場面もある、というアブレーション研究。足場の部品を「作るか否か」ではなく「測って決める」ための基準として置く。
